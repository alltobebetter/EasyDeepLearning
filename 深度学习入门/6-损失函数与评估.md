## 引言：为什么需要损失函数？

在前面的章节，我们学习了网络结构、训练技巧和优化器。但还有一个核心问题：**如何告诉模型它做得好不好？**

**比喻：教练与运动员**

想象你是一名跳水教练：

- **运动员**：神经网络
- **动作**：网络的预测结果
- **评分标准**：损失函数

如果没有明确的评分标准：
- 运动员不知道哪里做得好、哪里做得差
- 无法改进动作
- 训练毫无方向

**损失函数的作用：**
1. **量化差距**：告诉模型预测和真实答案差多少
2. **指导优化**：梯度下降沿着损失函数下降
3. **评估进展**：观察损失变化，判断训练是否有效

这一章，我们将学习各种"评分标准"（损失函数）和如何全面评估模型（评估指标）。

## 6.1 回归任务的损失函数

### 6.1.1 均方误差 (MSE - Mean Squared Error)

**最常用的回归损失函数。**

**数学定义：**

```
MSE = (1/n) × Σ(预测值 - 真实值)²

例如：
真实值：[3, 5, 2, 7]
预测值：[2.5, 5.5, 2.2, 6.8]
误差：  [-0.5, 0.5, 0.2, -0.2]
误差²： [0.25, 0.25, 0.04, 0.04]
MSE = (0.25 + 0.25 + 0.04 + 0.04) / 4 = 0.145
```

**比喻：靶心射击**

想象你在射箭：

```
靶心（真实值）在中心
你的箭（预测值）可能偏离靶心

MSE就像这样计算偏差：
1. 测量每支箭到靶心的距离
2. 将距离平方（强调大偏差）
3. 取平均值

为什么平方？
- 偏左5cm和偏右5cm，都是5²=25分惩罚
- 偏离10cm比偏离5cm严重得多：10²=100 vs 5²=25（4倍惩罚！）
```

**特点：**

**对大误差敏感**：误差平方后，大误差惩罚更重

```
误差1：惩罚 = 1² = 1
误差2：惩罚 = 2² = 4（4倍）
误差5：惩罚 = 5² = 25（25倍）
误差10：惩罚 = 10² = 100（100倍）
```

**数学性质好**：可导，易优化

**物理意义明确**：对应能量/方差

**对异常值过度敏感**：一个极端错误会主导损失

**适用场景：**
- 预测房价、温度、销量等连续值
- 数据中没有极端异常值
- 希望严厉惩罚大错误

### 6.1.2 平均绝对误差 (MAE - Mean Absolute Error)

**对异常值更鲁棒的损失函数。**

**数学定义：**

```
MAE = (1/n) × Σ|预测值 - 真实值|

例如：
真实值：[3, 5, 2, 7]
预测值：[2.5, 5.5, 2.2, 6.8]
误差：  [-0.5, 0.5, 0.2, -0.2]
绝对值：[0.5, 0.5, 0.2, 0.2]
MAE = (0.5 + 0.5 + 0.2 + 0.2) / 4 = 0.35
```

**比喻：计程车费用**

```
MSE像是：
距离越远，价格指数增长（平方关系）
偏离1km → 收费1元
偏离2km → 收费4元
偏离10km → 收费100元（太贵了！）

MAE像是：
距离越远，价格线性增长
偏离1km → 收费1元
偏离2km → 收费2元
偏离10km → 收费10元（合理）
```

**MSE vs MAE对比：**

假设你预测房价，有一个极端错误：

```
数据：
样本1: 真实300万, 预测295万, 误差5万
样本2: 真实320万, 预测318万, 误差2万
样本3: 真实280万, 预测350万, 误差70万（极端错误！）
样本4: 真实310万, 预测312万, 误差2万

MSE计算：
(5² + 2² + 70² + 2²) / 4 = (25 + 4 + 4900 + 4) / 4 = 1233.25
（被样本3主导了！）

MAE计算：
(5 + 2 + 70 + 2) / 4 = 19.75
（样本3的影响被稀释了）
```

**特点：**

**对异常值鲁棒**：线性惩罚，不会被极端值主导

**直观易懂**：就是平均偏差距离

**不可导（在0点）**：优化稍微困难一点

**对小误差不够敏感**：不能像MSE那样"精益求精"

**适用场景：**
- 数据中有异常值/噪声
- 各个样本同等重要（不想被极端值左右）
- 房价预测、股价预测等（常有异常情况）

### 6.1.3 Huber Loss：MSE和MAE的折中

**在小误差时像MSE，在大误差时像MAE。**

**比喻：弹性评分系统**

想象一个有同理心的老师：

```
MSE老师（严厉）：
考89分：扣11²=121分惩罚
考60分：扣40²=1600分惩罚（太狠了！学生会放弃）

MAE老师（宽松）：
考89分：扣11分惩罚
考60分：扣40分惩罚（惩罚不够，学生不重视）

Huber老师（平衡）：
考89分（小错误）：扣11²分惩罚（严格要求）
考60分（大错误）：扣40分+固定惩罚（不至于让学生绝望）
```

**数学定义：**

```
对于每个样本：
  如果 |误差| ≤ δ:
    loss = 0.5 × 误差²        （像MSE）
  否则:
    loss = δ × (|误差| - 0.5δ)  （像MAE）

常用 δ = 1.0
```

**可视化：**

```
损失
 │        ╱ MSE (抛物线)
 │       ╱
 │      ╱
 │     ╱___Huber（在δ处转折）
 │    ╱
 │   ╱____MAE (直线)
 │  ╱
 └─────────────────→ 误差
   0      δ
```

**特点：**

**小误差敏感**（像MSE）：精确优化

**大误差鲁棒**（像MAE）：不被异常值主导

**处处可导**：优化友好

**可调节**：通过δ控制转折点

**适用场景：**
- 数据既要精确又有噪声
- 目标检测（位置回归）
- 强化学习

### 6.1.4 Log-Cosh Loss

**比Huber更平滑的损失函数。**

**数学定义：**

```
Log-Cosh = Σ log(cosh(预测值 - 真实值))

其中 cosh(x) = (e^x + e^(-x)) / 2
```

**特点：**

- 处处二阶可导（比Huber更光滑）
- 近似Huber，但更平滑
- 计算稍复杂

**比喻：豪华版Huber**

就像自动挡（Log-Cosh）vs 手动挡（Huber），功能类似但更平滑。

## 6.2 分类任务的损失函数

### 6.2.1 交叉熵损失 (Cross-Entropy Loss)

**分类任务的标准损失函数。**

#### 二分类：Binary Cross-Entropy (BCE)

**比喻：诚实度测试**

想象你在预测"这是不是一只猫"：

```
真实答案：是猫（标签=1）

你的预测（概率）：
方案A: 95%是猫 → 很自信且正确 → 奖励
方案B: 55%是猫 → 不太自信但对了 → 小奖励
方案C: 30%是猫 → 错了且很自信 → 严厉惩罚！

交叉熵会根据你的"自信程度"和"正确性"来评分：
- 自信+正确 → 低损失
- 不自信+正确 → 中等损失
- 自信+错误 → 高损失（惩罚自信的错误）
```

**数学定义：**

```
BCE = -[y×log(p) + (1-y)×log(1-p)]

其中：
y = 真实标签（0或1）
p = 预测概率（0到1之间）

分情况：
如果y=1（真的是猫）：
  loss = -log(p)
  p=0.95 → loss = -log(0.95) = 0.05（很小）
  p=0.55 → loss = -log(0.55) = 0.60（中等）
  p=0.05 → loss = -log(0.05) = 3.00（很大）

如果y=0（不是猫）：
  loss = -log(1-p)
  p=0.05 → loss = -log(0.95) = 0.05（很小）
  p=0.55 → loss = -log(0.45) = 0.80（较大）
  p=0.95 → loss = -log(0.05) = 3.00（很大）
```

**直观理解：**

```
预测概率 → 损失（y=1时）
0.99 → 0.01  非常自信且对，奖励
0.90 → 0.11  自信且对，好
0.70 → 0.36  ✓ 对了，但不够自信
0.50 → 0.69  △ 猜的？
0.30 → 1.20  ✗ 错了
0.10 → 2.30  ✗✗ 大错特错
0.01 → 4.61  ✗✗✗ 极其错误！
```

**为什么用log？**

**比喻：惩罚的非线性**

```
考试评分：
90分（预测0.9正确）→ 扣10分
80分（预测0.8正确）→ 扣20分
70分（预测0.7正确）→ 扣30分

但神经网络需要更激进：
预测0.9正确 → 小惩罚（接近了！）
预测0.5正确 → 中等惩罚（还差很多）
预测0.1正确 → 巨大惩罚（完全错了！）

log函数提供这种非线性惩罚：
-log(0.9) = 0.11
-log(0.5) = 0.69（6倍）
-log(0.1) = 2.30（21倍）
```

#### 多分类：Categorical Cross-Entropy

**比喻：多选题评分**

```
问题：这是什么动物？
选项：猫、狗、鸟
正确答案：猫

你的预测（Softmax后的概率）：
方案A: 猫80%, 狗15%, 鸟5%  → 好！
方案B: 猫40%, 狗40%, 鸟20% → 不确定
方案C: 猫10%, 狗70%, 鸟20% → 错了！

交叉熵只看正确类别的概率：
方案A: loss = -log(0.80) = 0.22（低）
方案B: loss = -log(0.40) = 0.92（中）
方案C: loss = -log(0.10) = 2.30（高）
```

**数学定义：**

```
CE = -Σ y_i × log(p_i)

其中：
y_i = 第i类的真实标签（one-hot编码，只有正确类是1，其他是0）
p_i = 第i类的预测概率

例如：
真实标签：[1, 0, 0]（是猫）
预测概率：[0.7, 0.2, 0.1]
CE = -[1×log(0.7) + 0×log(0.2) + 0×log(0.1)]
   = -log(0.7)
   = 0.36

只关心正确类别的概率！
```

**特点：**

**概率解释清晰**：基于信息论

**梯度性质好**：不会出现梯度饱和（与Softmax配合时）

**适合概率输出**：最后一层用Softmax

**标准选择**：分类任务的默认损失

**适用场景：**
- 图像分类
- 文本分类
- 任何多分类任务

### 6.2.2 Focal Loss：处理类别不平衡

**问题：数据不平衡**

**比喻：偏心的老师**

想象一个班级：

```
正常情况（平衡数据）：
优等生：20人
普通生：20人
差生：  20人
老师对每个人都同等关注 ✓

不平衡情况：
优等生：190人（容易样本）
差生：  10人（困难样本）

如果用标准交叉熵：
模型倾向于：把所有人都预测为"优等生"
准确率：190/200 = 95%（看起来很高！）
但实际上：模型根本没学会识别"差生"
```

**Focal Loss的解决方案：**

**核心思想：降低容易样本的权重，聚焦困难样本。**

**比喻：因材施教**

```
标准交叉熵（一视同仁）：
优等生（容易）：老师花1小时
差生（困难）：  老师花1小时

Focal Loss（聚焦困难）：
优等生（已经会了）：老师花0.1小时
差生（需要帮助）：  老师花10小时
```

**数学定义：**

```
Focal Loss = -(1-p)^γ × log(p)

其中：
p = 预测正确的概率
γ = 聚焦参数（通常取2）

调制因子：(1-p)^γ
```

**工作原理：**

```
样本类型           预测概率p    调制因子(1-p)²   最终权重
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
容易样本（高置信）   0.9         0.1² = 0.01      1%权重
中等样本            0.7         0.3² = 0.09      9%权重
困难样本（低置信）   0.5         0.5² = 0.25      25%权重
很困难样本          0.3         0.7² = 0.49      49%权重
极困难样本          0.1         0.9² = 0.81      81%权重

容易样本的损失被大幅降低，模型关注困难样本！
```

**对比：**

```
标准CE vs Focal Loss（γ=2）

预测概率p   标准CE损失   Focal Loss   降低比例
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
0.9 (容易)   0.105       0.001        99%↓
0.7 (中等)   0.357       0.032        91%↓
0.5 (困难)   0.693       0.173        75%↓
0.3 (很难)   1.204       0.590        51%↓

容易样本的权重被大幅降低！
```

**特点：**

**自动处理类别不平衡**：不需要手动调整样本权重

**聚焦困难样本**：让模型更关注难学的样本

**兼容性好**：可以直接替换交叉熵

**可调节**：通过γ控制聚焦程度

**适用场景：**
- 目标检测（背景 vs 物体，极度不平衡）
- 医学诊断（正常 vs 异常，正常样本多得多）
- 欺诈检测（正常交易 vs 欺诈，欺诈极少）

### 6.2.3 标签平滑 (Label Smoothing)

**问题：模型过度自信**

**比喻：狂妄的学生**

```
考试成绩：
学生A：每道题都100%自信，结果全对 → 好
学生B：每道题都100%自信，结果错了几道 → 惨！

模型也一样：
过度自信的模型：
  预测猫的概率 = 99.99%（太绝对了）
  如果错了，损失会非常大
  而且容易过拟合

理想的模型：
  预测猫的概率 = 90%（留一点余地）
  更谦虚，泛化能力更好
```

**标签平滑的解决方案：**

软化硬标签，不让模型追求100%的极端概率。

**数学定义：**

```
原始标签（硬标签）：[1, 0, 0]（100%是猫）

平滑后标签：
y_smooth = (1-ε)×y_hard + ε/K

其中：
ε = 平滑参数（通常0.1）
K = 类别数
y_hard = 原始标签

例如：3个类别，ε=0.1
原始：[1, 0, 0]
平滑：[0.9×1 + 0.1/3, 0.9×0 + 0.1/3, 0.9×0 + 0.1/3]
    = [0.933, 0.033, 0.033]

意思：我90%确定是猫，但给其他类别留3%的可能性
```

**对比：**

```
训练目标         模型预测      损失
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
硬标签[1,0,0]   [0.9,0.05,0.05]  中等
硬标签[1,0,0]   [0.99,0.005,0.005] 更小 → 鼓励极端预测

软标签[0.93,0.03,0.03]  [0.9,0.05,0.05]  小
软标签[0.93,0.03,0.03]  [0.99,0.005,0.005] 大 → 惩罚过度自信

软标签阻止模型追求极端概率！
```

**为什么有效？**

1. **防止过拟合**：不让模型对训练数据过度自信
2. **正则化效果**：相当于一种隐式正则化
3. **鼓励不同类别的输出有差异但不极端**

**比喻：留有余地的智慧**

```
极端思维（硬标签）：
"我100%确定这是对的！"
→ 如果错了，会很惨
→ 思维僵化，不容纳新信息

谦虚思维（软标签）：
"我90%确定这是对的，但可能有我不知道的情况"
→ 更开放的心态
→ 泛化能力更强
```

**特点：**

**提高泛化**：减少过拟合

**实现简单**：只需修改标签

**广泛适用**：几乎所有分类任务

**轻微降低训练准确率**：但测试性能通常更好

**适用场景：**
- 大规模分类（ImageNet）
- 过拟合严重的任务
- Transformer模型

**推荐配置：**
```
ε = 0.1（标准选择）
ε = 0.2（更强的平滑）
ε = 0.05（轻微平滑）
```

## 6.3 特殊任务的损失函数

### 6.3.1 目标检测：组合损失

**目标检测需要同时完成三个任务：**

1. **分类**：这是什么物体？（猫/狗/车）
2. **定位**：物体在哪里？（边界框坐标）
3. **置信度**：这里真的有物体吗？（前景/背景）

**比喻：寻宝游戏**

```
任务1（分类）：找到的是金币还是钻石？
任务2（定位）：宝物在地图的哪个位置？
任务3（置信度）：这个位置真的有宝物吗？

总损失 = 分类损失 + 定位损失 + 置信度损失
```

**YOLO的损失函数：**

```
总损失 = λ_coord × 定位损失（MSE）
       + λ_obj × 目标置信度损失（BCE）
       + λ_noobj × 背景置信度损失（BCE）
       + 分类损失（CE）

权重系数：
λ_coord = 5.0  （定位很重要，加大权重）
λ_obj = 1.0    （目标置信度）
λ_noobj = 0.5  （背景置信度，降低权重）
```

**为什么需要不同的权重？**

```
问题：类别不平衡
一张图片中：
- 背景框：1000个（大部分都是背景）
- 目标框：5个（实际有物体的很少）

如果权重相同：
模型会倾向于：把所有框都预测为"没有物体"
因为这样loss最小（背景框太多了）

解决：降低背景框的权重（λ_noobj = 0.5）
```

### 6.3.2 语义分割：像素级损失

**语义分割：给图像的每个像素分类。**

**比喻：填色游戏**

```
输入：黑白轮廓图
输出：每个像素都要标注颜色（类别）

挑战：
- 像素数量巨大（512×512 = 262,144个像素）
- 类别不平衡（天空占很大面积，行人很小）
```

#### Dice Loss

**专门为分割设计的损失函数。**

**比喻：重叠度评分**

```
想象两个圆：
圆A：真实的物体区域
圆B：预测的物体区域

Dice系数 = 2 × (A和B的重叠面积) / (A的面积 + B的面积)

完全重合：Dice = 1.0（完美）
部分重合：Dice = 0.6（还行）
完全不重合：Dice = 0.0（糟糕）

Dice Loss = 1 - Dice系数
```

**数学定义：**

```
Dice = 2×Σ(y_i × p_i) / (Σy_i + Σp_i)

其中：
y_i = 真实标签（像素i是否属于目标）
p_i = 预测概率（像素i属于目标的概率）

Dice Loss = 1 - Dice
```

**为什么对不平衡鲁棒？**

```
场景：背景99%，前景1%

如果用交叉熵：
把所有像素预测为背景 → 准确率99%
但完全没识别出前景！

如果用Dice Loss：
只看前景和预测的重叠
如果前景一个都没识别 → Dice=0，Loss=1（很大！）
强制模型关注小目标
```

**特点：**

**对类别不平衡鲁棒**

**直接优化分割质量**（不是间接通过像素准确率）

**适合小目标**

**训练初期可能不稳定**

**实践中常用组合：**

```
Total Loss = CE Loss + Dice Loss

结合两者优点：
- CE：稳定训练，像素级监督
- Dice：关注整体重叠，处理不平衡
```

### 6.3.3 生成对抗网络 (GAN)：对抗损失

**GAN的目标：生成逼真的假图像。**

**比喻：伪造者vs鉴定师**

```
伪造者（生成器G）：
目标：画出假钞，骗过鉴定师

鉴定师（判别器D）：
目标：识别真钞和假钞

对抗训练：
1. 伪造者生成假钞
2. 鉴定师判断真假
3. 伪造者根据鉴定师的反馈改进
4. 鉴定师提高鉴定能力
5. 循环往复，直到假钞"以假乱真"
```

**损失函数：**

```
判别器D的损失：
L_D = -[log(D(真实图像)) + log(1-D(生成图像))]
目标：把真的判断为真，假的判断为假

生成器G的损失：
L_G = -log(D(生成图像))
目标：让判别器把假的判断为真
```

**训练过程：**

```
初期：
生成器：画得很烂，容易被识破
判别器：轻松识别真假

中期：
生成器：越来越像真的
判别器：需要更仔细才能分辨

后期：
生成器：几乎以假乱真
判别器：难以分辨（准确率接近50%，相当于猜测）
```

**平衡难题：**

```
问题：判别器太强 → 生成器学不动
     判别器太弱 → 生成器学不到有用信号

解决：
1. 交替训练（训练1次G，训练k次D）
2. 使用WGAN等改进损失
3. 谱归一化等技巧
```

### 6.3.4 Contrastive Loss：度量学习

**目标：学习相似度，而不是具体类别。**

**比喻：认亲游戏**

```
任务：判断两个人是不是一家人
不需要知道他们具体是谁

Contrastive Learning：
正样本对（同一个人的不同照片）：
  → 拉近距离

负样本对（不同人的照片）：
  → 推远距离

最终：
相似的东西在特征空间中聚在一起
不相似的东西被推开
```

**数学定义：**

```
Contrastive Loss = 
  y × d²                      （相似对，距离越近越好）
  + (1-y) × max(margin-d, 0)² （不相似对，至少距离margin）

其中：
d = 特征向量的欧式距离
y = 标签（1=相似，0=不相似）
margin = 边界值（如1.0）
```

**可视化：**

```
特征空间中：

相似样本对（同一只猫的不同照片）：
🐱1 ←→ 🐱2  距离0.1 ✓ 很近！

不相似样本对（猫和狗）：
🐱 ←———————————→ 🐕  距离3.0 ✓ 很远！

如果不相似但很近（违反margin）：
🐱 ←→ 🐕  距离0.5 ✗ 太近了，增大损失！
```

**应用场景：**

1. **人脸识别**：
   ```
   不需要训练所有人的类别
   只需学习人脸特征
   新来的人：直接比较特征相似度
   ```

2. **图像检索**：
   ```
   输入：一张猫的图片
   输出：数据库中相似的猫图片
   不需要"猫"的标签，只需相似度
   ```

3. **推荐系统**：
   ```
   相似用户的特征向量应该接近
   用户和他喜欢的商品特征应该接近
   ```

**现代变体：Triplet Loss**

```
三元组：（锚点，正样本，负样本）
例如：（猫A，猫B，狗）

目标：
distance(猫A, 猫B) < distance(猫A, 狗)

损失：
loss = max(d(A,P) - d(A,N) + margin, 0)

相似的要更近，不相似的要更远，至少差margin
```

## 6.4 评估指标：全面评估模型

**损失函数 vs 评估指标**

**比喻：考试vs就业**

```
损失函数（考试成绩）：
- 训练过程中用来优化
- 可微分，可以求梯度
- 例如：交叉熵

评估指标（就业能力）：
- 评估模型最终表现
- 不一定可微分
- 例如：准确率、F1分数

就像：
考试成绩（损失）是为了学习知识
但最终看的是能否胜任工作（指标）
```

### 6.4.1 分类任务的评估指标

#### 准确率 (Accuracy)

**最直观的指标。**

```
准确率 = 预测正确的样本数 / 总样本数

例如：
总共100个样本
预测对了85个
准确率 = 85%
```

**优点：**
简单直观
易于理解

**缺点：**
类别不平衡时误导

**比喻：不平衡的陷阱**

```
医学诊断：
正常人：95人
患者：  5人

模型策略：把所有人都预测为"正常"
准确率 = 95%（看起来很高！）

但实际上：
没有识别出任何患者！完全失败！
```

#### 混淆矩阵 (Confusion Matrix)

**更详细的分类结果。**

**二分类混淆矩阵：**

```
                预测
              正类    负类
真  正类    TP (✓)   FN (✗)
实  负类    FP (✗)   TN (✓)

TP (True Positive)：真阳性 - 预测是正的，实际也是正的 ✓
TN (True Negative)：真阴性 - 预测是负的，实际也是负的 ✓
FP (False Positive)：假阳性 - 预测是正的，实际是负的 ✗ (误报)
FN (False Negative)：假阴性 - 预测是负的，实际是正的 ✗ (漏报)
```

**比喻：火灾报警系统**

```
TP：着火了，报警了 ✓ （正确）
TN：没着火，没报警 ✓ （正确）
FP：没着火，报警了 ✗ （误报，虚惊一场）
FN：着火了，没报警 ✗ （漏报，危险！）
```

**实例：疾病诊断**

```
总共1000人，10人真的有病

模型A（保守）：预测2人有病
结果：TP=2, FN=8, FP=0, TN=990
→ 准确率=99.2%，但漏诊了80%的患者！

模型B（激进）：预测100人有病
结果：TP=10, FN=0, FP=90, TN=900
→ 准确率=91%，但误诊了90人

哪个更好？取决于任务！
```

#### 精确率 (Precision)

**预测为正的样本中，有多少真的是正的？**

```
Precision = TP / (TP + FP)
          = 真阳性 / 所有预测为正的

比喻：
精确率 = 预测的质量 = "我说是正的，有多可信？"
```

**例子：垃圾邮件过滤**

```
预测100封邮件是垃圾邮件
其中80封真的是垃圾邮件，20封是正常邮件

Precision = 80/100 = 80%

意义：
我标记为"垃圾邮件"的，有80%是对的
但有20%误杀了正常邮件！

如果Precision低：
用户会错过重要邮件（FP太多）
```

#### 召回率 (Recall / Sensitivity)

**真正为正的样本中,有多少被预测出来了？**

```
Recall = TP / (TP + FN)
       = 真阳性 / 所有真正是正的

比喻：
召回率 = 预测的完整性 = "我找到了多少正样本？"
```

**例子：癌症筛查**

```
100人真的有癌症
系统检测出80人

Recall = 80/100 = 80%

意义：
漏诊了20人！可能致命！

医疗诊断中：
Recall非常重要，宁可误诊，不可漏诊
```

#### Precision vs Recall的权衡

**比喻：撒网捕鱼**

```
场景：池塘里有100条鱼（真正的目标）

策略A（高Precision，低Recall）：
用小网，只捞最明显的
捞了10条，10条都是鱼（Precision=100%）
但漏了90条（Recall=10%）

策略B（低Precision，高Recall）：
用大网，连泥带水都捞
捞了200个东西，包含90条鱼（Recall=90%）
但也捞了110个石头（Precision=45%）

策略C（平衡）：
适中大小的网
捞了120个东西，包含80条鱼
Precision=67%，Recall=80%
```

**不同场景的选择：**

```
高Precision场景（宁可漏过，不要误报）：
- 垃圾邮件过滤（误杀正常邮件很烦）
- 推荐系统（推荐错了很烦）
- 信用卡欺诈检测初筛（避免误伤正常用户）

高Recall场景（宁可误报，不要漏过）：
- 医疗诊断（漏诊可能致命）
- 安检系统（遗漏危险品后果严重）
- 传染病筛查（不能放过任何可能）

平衡场景：
- 搜索引擎（既要相关，也要全面）
```

#### F1分数：调和平均

**综合考虑Precision和Recall。**

```
F1 = 2 × (Precision × Recall) / (Precision + Recall)

这是调和平均，而不是算术平均
```

**为什么用调和平均？**

```
算术平均的问题：
Precision=100%, Recall=10%
算术平均 = (100+10)/2 = 55%（看起来还行？）

调和平均（F1）：
F1 = 2×100×10/(100+10) = 18.2%（揭示了不平衡）

调和平均会被小的值主导！
必须两个都高，F1才高
```

**比喻：木桶原理**

```
算术平均：看平均身高
一个姚明（2.26m）+ 一个儿童（1m） = 平均1.63m

调和平均：看短板
木桶能装多少水取决于最短的板
Precision和Recall必须都高，才能有高F1
```

**不同的F-score:**

```
F1：平等对待Precision和Recall

F2：更重视Recall
F2 = 5 × (P×R) / (4×P + R)
适用：医疗诊断（不能漏诊）

F0.5：更重视Precision
F0.5 = 1.25 × (P×R) / (0.25×P + R)
适用：垃圾邮件（不能误杀）
```

#### PR曲线与AP

**Precision-Recall曲线**

**比喻：阈值的影响**

```
分类器输出概率，我们需要设定阈值：

阈值=0.9（严格）：
只有很自信的才判为正类
→ 高Precision（判的都对）
→ 低Recall（漏了很多）

阈值=0.1（宽松）：
稍微有点可能就判为正类
→ 低Precision（误判很多）
→ 高Recall（几乎不漏）

PR曲线：画出不同阈值下的P和R
```

**Average Precision (AP):**

```
AP = PR曲线下的面积

AP=1.0：完美
AP=0.5：一般
AP<0.3：差

目标检测常用mAP（mean AP）：
对每个类别计算AP，然后取平均
```

#### ROC曲线与AUC

**ROC (Receiver Operating Characteristic) 曲线**

```
纵轴：True Positive Rate (TPR) = Recall = TP/(TP+FN)
横轴：False Positive Rate (FPR) = FP/(FP+TN)

TPR：捕获了多少真正的正样本（越高越好）
FPR：误报了多少负样本（越低越好）
```

**比喻：雷达灵敏度**

```
低灵敏度（高阈值）：
TPR=10%（漏掉很多真飞机）
FPR=1%（误报很少）

高灵敏度（低阈值）：
TPR=99%（几乎不漏飞机）
FPR=20%（误报很多，鸟也报）

ROC曲线：不同灵敏度下的TPR vs FPR
```

**AUC (Area Under Curve):**

```
AUC = ROC曲线下的面积

AUC=1.0：完美分类器
AUC=0.9：优秀
AUC=0.5：随机猜测（无用）
AUC<0.5：比随机猜测还差

AUC的含义：
随机取一个正样本和一个负样本
分类器给正样本打分更高的概率
```

**PR曲线 vs ROC曲线:**

```
使用PR曲线：
- 类别不平衡（正样本很少）
- 关注正类的性能
- 例如：疾病诊断、欺诈检测

使用ROC曲线：
- 类别平衡
- 关注整体性能
- 例如：二分类基准测试
```

### 6.4.2 回归任务的评估指标

#### MAE、MSE、RMSE

```
MAE (Mean Absolute Error)：
平均绝对误差，容易理解
MAE = 5万 → 平均偏差5万

MSE (Mean Squared Error)：
平均平方误差，强调大误差
MSE = 25万² → 不直观

RMSE (Root Mean Squared Error)：
MSE开根号，单位和原始数据一致
RMSE = 5万 → 和MAE类似，但对大误差更敏感
```

#### R² (决定系数)

**模型解释了多少数据的变化？**

```
R² = 1 - (模型残差平方和 / 总变差)

R²=1.0：完美拟合
R²=0.7：解释了70%的变化（还不错）
R²=0.0：和均值预测一样（无用）
R²<0：比均值预测还差（糟糕）
```

**比喻：解释能力**

```
预测房价：
数据变化很大（200万到800万）

模型A：R²=0.9
解释了90%的价格变化（很好！）
主要因素：位置、面积、学区

模型B：R²=0.3
只解释了30%的变化
还有70%不知道为什么
```

#### MAPE (平均绝对百分比误差)

```
MAPE = (1/n) × Σ|预测-真实|/真实 × 100%

例如：
真实房价：100万
预测房价：95万
误差率：5%

优点：相对误差，不受量纲影响
缺点：真实值为0时无定义
```

### 6.4.3 目标检测的评估指标

#### IoU (Intersection over Union)

**衡量两个框的重叠程度。**

```
IoU = (A∩B) / (A∪B)
    = 重叠面积 / 总面积

比喻：猜拳重叠度
两个人出拳：
完全重合：IoU=1.0
部分重合：IoU=0.5
完全不重合：IoU=0.0
```

**可视化：**

```
真实框：   ┌────┐
预测框：     ┌────┐

重叠部分：   ┌──┐  （小矩形）
总面积：   ┌──────┐（大矩形）

IoU = 小矩形 / 大矩形
```

**阈值判断：**

```
IoU > 0.5：通常认为预测正确
IoU > 0.7：较严格的标准
IoU > 0.9：非常精确
```

#### mAP (mean Average Precision)

**目标检测的标准指标。**

```
步骤：
1. 对每个类别：
   - 按置信度排序所有检测框
   - 计算不同Recall下的Precision
   - 计算AP（曲线下面积）

2. 对所有类别取平均 → mAP
```

**不同的mAP标准：**

```
mAP@0.5：IoU阈值=0.5
比较宽松，常用于PASCAL VOC

mAP@0.75：IoU阈值=0.75
更严格

mAP@[0.5:0.95]：COCO标准
IoU从0.5到0.95，步长0.05，取平均
最严格，最全面
```

### 6.4.4 分割任务的评估指标

#### Pixel Accuracy

```
准确率 = 预测正确的像素数 / 总像素数

简单但可能误导（类别不平衡）
```

#### Mean IoU (mIoU)

**每个类别计算IoU，然后取平均。**

```
对于类别i：
IoU_i = TP / (TP + FP + FN)

mIoU = (1/K) × Σ IoU_i

例如：
天空：IoU=0.95
道路：IoU=0.90
行人：IoU=0.70
mIoU = (0.95+0.90+0.70)/3 = 0.85
```

**比喻：公平的评分**

```
像素准确率：
天空占90%的像素，预测对了天空 → 90%准确率
但完全没识别出行人！

mIoU：
必须每个类别都识别好，才能有高mIoU
对小目标（行人）和大目标（天空）同等重要
```

## 6.5 选择合适的损失函数和指标

### 6.5.1 损失函数选择指南

**决策树：**

```
任务类型？
│
├─ 回归
│   ├─ 数据干净，无异常值 → MSE
│   ├─ 有异常值 → MAE 或 Huber Loss
│   └─ 目标检测中的框回归 → Smooth L1（Huber变体）
│
├─ 二分类
│   ├─ 平衡数据 → Binary Cross-Entropy
│   ├─ 不平衡数据 → Focal Loss 或 加权BCE
│   └─ 需要概率校准 → BCE + Label Smoothing
│
├─ 多分类
│   ├─ 单标签分类 → Categorical Cross-Entropy
│   ├─ 多标签分类 → Binary Cross-Entropy（每个类别）
│   ├─ 类别不平衡 → Focal Loss
│   └─ 大规模分类，易过拟合 → CE + Label Smoothing
│
├─ 语义分割
│   ├─ 平衡数据 → Cross-Entropy
│   ├─ 不平衡数据 → Dice Loss 或 Focal Loss
│   └─ 推荐：CE + Dice Loss（组合）
│
├─ 目标检测
│   └─ 分类 + 回归 + 置信度的组合损失
│
├─ 度量学习
│   └─ Contrastive Loss 或 Triplet Loss
│
└─ 生成任务
    ├─ GAN → 对抗损失
    ├─ VAE → 重构损失 + KL散度
    └─ 扩散模型 → 去噪损失
```

### 6.5.2 评估指标选择指南

```
任务类型？
│
├─ 分类
│   ├─ 平衡数据 → Accuracy
│   ├─ 不平衡数据 → F1、Precision、Recall、AUC
│   ├─ 二分类 → AUC-ROC
│   ├─ 多分类 → F1 (macro/micro)
│   └─ 需要调整阈值 → PR曲线、ROC曲线
│
├─ 回归
│   ├─ 关心绝对误差 → MAE、RMSE
│   ├─ 关心相对误差 → MAPE、R²
│   └─ 对比模型 → R²
│
├─ 目标检测
│   └─ mAP（不同IoU阈值）
│
├─ 语义分割
│   └─ mIoU、Pixel Accuracy
│
└─ 生成任务
    ├─ 图像生成 → FID、IS
    └─ 文本生成 → BLEU、ROUGE
```

### 6.5.3 实战建议

#### 1. 损失函数和指标可以不同

```
训练用：Cross-Entropy（可微分，优化友好）
评估用：F1、AUC（更贴近实际业务）

就像：
训练时看"考试成绩"（损失）
评估时看"工作能力"（指标）
```

#### 2. 多指标综合评估

**不要只看一个指标！**

```
分类任务至少看：
- 准确率（整体）
- 混淆矩阵（细节）
- F1分数（平衡）
- AUC（阈值不敏感）

回归任务至少看：
- RMSE（整体）
- MAE（鲁棒性）
- R²（解释能力）
- 残差分布（诊断）
```

#### 3. 业务指标最重要

```
技术指标（Accuracy、F1）：
训练和调试时使用

业务指标：
最终决策依据

例如：推荐系统
技术指标：点击率预测的AUC=0.85
业务指标：用户留存率、GMV、用户满意度

技术指标好，业务指标不一定好！
```

#### 4. 类别不平衡的处理

```
问题：99%正常，1%异常

解决方案：

方法1：重采样
- 过采样：复制少数类
- 欠采样：减少多数类

方法2：类别权重
loss = w_positive × loss_positive + w_negative × loss_negative
w_positive = 99, w_negative = 1

方法3：使用Focal Loss
自动降低容易样本权重

方法4：改变评估指标
不看Accuracy，看F1或AUC
```

## 本章小结

我们学习了损失函数和评估指标的完整知识体系：

### 回归损失函数

1. **MSE** - 对大误差敏感，标准选择
2. **MAE** - 对异常值鲁棒
3. **Huber Loss** - MSE和MAE的折中
4. **Log-Cosh** - 更平滑的Huber

### 分类损失函数

1. **Cross-Entropy** - 分类任务的标准
2. **Focal Loss** - 处理类别不平衡
3. **Label Smoothing** - 防止过度自信

### 特殊损失函数

1. **目标检测** - 组合损失（分类+回归+置信度）
2. **语义分割** - Dice Loss（处理不平衡）
3. **GAN** - 对抗损失
4. **度量学习** - Contrastive/Triplet Loss

### 评估指标

**分类任务：**
- Accuracy（简单）
- Precision/Recall（不平衡）
- F1分数（综合）
- AUC（阈值不敏感）
- 混淆矩阵（详细分析）

**回归任务：**
- MAE/RMSE（误差）
- R²（解释能力）
- MAPE（相对误差）

**检测/分割：**
- mAP（检测）
- mIoU（分割）

### 核心原则

1. **损失函数用于训练，指标用于评估**
   - 损失：可微分，优化友好
   - 指标：业务相关，可解释

2. **根据数据特点选择**
   - 平衡数据 → 标准损失
   - 不平衡 → Focal/Dice/加权

3. **多指标综合评估**
   - 不要只看一个数字
   - 混淆矩阵揭示细节

4. **业务指标最重要**
   - 技术指标是手段
   - 业务目标是目的

**比喻总结：**

> 损失函数是教练的评分标准，告诉运动员如何改进动作。
> 
> 评估指标是比赛裁判的评分，决定运动员的最终成绩。
> 
> 训练时听教练的（优化损失），比赛时看裁判的（评估指标）！
