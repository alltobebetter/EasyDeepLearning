## 3.1 全连接神经网络 (Fully Connected Network / MLP)

### 核心概念：最基础的网络结构

**比喻：班级投票**

想象一个班级要选班长，有30个学生投票。每个学生（输入）都可以给所有候选人（神经元）投票，没有任何限制。这就是"全连接"：**每个输入都连接到每个神经元**。

### 全连接网络的结构

**层层相连的简单设计：**

```
输入层 (784个神经元，代表28×28像素的图片)
↓ (每个输入连接到下一层的每个神经元)
隐藏层1 (256个神经元)
↓ (每个神经元连接到下一层的每个神经元)
隐藏层2 (128个神经元)
↓
输出层 (10个神经元，代表0-9十个数字)
```

**完整的例子：手写数字识别**

假设我们要识别手写数字"5"：

**第一步：输入层**
- 一张28×28的灰度图片
- 展平成784个数字（每个像素一个数值0-255）
- 就像把一张照片撕成784个小碎片

**第二步：第一个隐藏层（256个神经元）**

每个神经元都要：
- 接收全部784个输入
- 用自己的784个权重计算加权和
- 通过激活函数（比如ReLU）

比喻：256个评委，每个人都要看完整张图片的所有细节，然后给出自己的判断。

- 神经元1：专门识别"横向笔画"，输出0.8（发现了很多横线）
- 神经元2：专门识别"竖向笔画"，输出0.3（没什么竖线）
- 神经元3：专门识别"弧形"，输出0.9（发现了弧形）
- ...
- 神经元256：专门识别某种特殊模式

**第三步：第二个隐藏层（128个神经元）**

这层接收第一层的256个输出，进行更高级的判断：

- 神经元1：结合"横线"和"弧形"，判断可能是数字"5"或"6"
- 神经元2：结合其他特征，排除其他数字的可能性
- ...

**第四步：输出层（10个神经元）**

最后一层给出对每个数字的"信心度"：

```
数字0: 0.01 (1%的可能性)
数字1: 0.02 (2%的可能性)
数字2: 0.03
数字3: 0.05
数字4: 0.08
数字5: 0.75 (75%的可能性) ← 最高！
数字6: 0.03
数字7: 0.01
数字8: 0.01
数字9: 0.01
```

模型判断：这是数字"5"！

### 全连接网络的优缺点

**优点：**
**简单易懂**：结构直观，容易理解和实现
**通用性强**：理论上可以逼近任何函数（万能近似定理）
**易于调试**：问题容易定位和解决

**缺点：**
**参数量巨大**：如果输入是1000×1000的图片（100万像素），第一层就需要100万×256个连接！
**容易过拟合**：参数太多，容易记住训练数据而不是学习规律
**忽略空间结构**：把图片展平后，丢失了像素之间的位置关系
**计算量大**：每层都要进行大量的矩阵运算

**比喻：** 就像用最原始的方法记忆，把整本书的每个字都背下来（参数量大），而不是理解书的结构和逻辑（利用空间结构）。

### 全连接网络的适用场景

**适合：**
- 表格数据（如房价预测：面积、地段、年份等特征）
- 小规模图像（如MNIST手写数字：28×28）
- 作为其他网络的最后几层（特征已经提取好了）

**不适合：**
- 大规模图像（如ImageNet：224×224×3）
- 需要保留空间结构的任务
- 序列数据（如文本、时间序列）

## 3.2 卷积神经网络 (CNN - Convolutional Neural Network)

### 核心概念：专为图像设计的网络

**全连接网络的问题**

假设你要识别一张1000×1000的彩色照片：
- 输入：1000×1000×3 = 300万个数值
- 如果第一层有1000个神经元
- 需要的权重数：300万×1000 = **30亿个参数**！

这太疯狂了！而且把图片展平后，相邻像素的关系都丢失了。

**CNN的革命性想法**

**比喻：警察巡逻 vs 监控整个城市**

传统全连接网络像一个站在高处的人，试图同时监控整个城市的每个角落（每个神经元看整张图）。

CNN像派出一队警察，每个警察只负责巡逻一小片区域（局部感知），但整个城市都被覆盖了。而且警察们用相同的标准执法（权值共享）。

### CNN的三大核心思想

#### 1. 局部感知 (Local Connectivity)

**比喻：看报纸**

当你看报纸上的一个字时，你不需要同时看整版报纸的所有字。你只需要看这个字周围的一小块区域，就能理解这个字。

**在CNN中：**
- 每个神经元只看图片的一小块区域（比如3×3或5×5）
- 这个小区域叫做"感受野"

**例子：检测边缘**

```
原始图片的一小块：
[100, 100, 100]
[100, 0, 0]
[100, 0, 0]

这块区域的特征：从左到右有一个明显的边界（亮→暗）
```

一个神经元只需要看这个3×3的小区域，就能判断"这里有一条竖直的边缘"。

#### 2. 权值共享 (Weight Sharing)

**比喻：用同一个模板盖章**

想象你要检查一批产品是否有划痕。你不需要为每个产品准备不同的检查工具，而是用**同一个放大镜**依次检查每个产品。

**在CNN中：**
- 同一个"卷积核"（滤波器）在整张图片上滑动
- 无论扫描到哪个位置，用的都是**相同的权重**

**为什么这样做？**

因为"边缘"、"角点"、"纹理"这些特征在图片的不同位置都可能出现。左上角的边缘检测器应该和右下角的边缘检测器是一样的。

**巨大的好处：参数大幅减少**

- 全连接：300万×1000 = 30亿个参数
- CNN（使用3×3卷积核）：3×3×3（RGB三通道）×32个卷积核 = 只需要864个参数！

减少了**300万倍**！

#### 3. 池化 (Pooling)：降采样

**比喻：看缩略图**

当你浏览手机相册时，你看的是缩略图，不是原图。虽然缩略图小，但你依然能认出照片内容。

**池化的作用：**
- 减小数据尺寸（如从100×100压缩到50×50）
- 保留主要特征
- 增强鲁棒性（对微小位移不敏感）

**最大池化 (Max Pooling)：取区域内的最大值**

```
原始4×4区域： 最大池化后（2×2）：
[1, 3, 2, 4] 
[5, 6, 7, 8] → [6, 8]
[2, 1, 3, 5] [4, 7]
[4, 2, 7, 6]
```

每2×2的区域取最大值，尺寸减半，但保留了"最强的特征"。

### CNN的完整工作流程

让我们用一个完整的例子来理解：**识别一张猫的照片**

**原始输入：224×224×3的彩色图片**

**第一层：卷积层1 + ReLU + 池化**

1. **卷积操作**（64个3×3的卷积核）

比喻：64个不同的"放大镜"扫描图片，每个放大镜寻找不同的特征：
- 卷积核1：寻找水平边缘
- 卷积核2：寻找竖直边缘
- 卷积核3：寻找45度斜线
- 卷积核4：寻找圆形边缘
- ...
- 卷积核64：寻找某种特殊纹理

每个卷积核扫描整张图片，生成一个"特征图"（Feature Map）。

输出：64个224×224的特征图

2. **激活函数（ReLU）**
- 引入非线性
- 负值变为0，正值保持

3. **池化（2×2最大池化）**
- 尺寸减半：224×224 → 112×112
- 输出：64个112×112的特征图

**第二层：卷积层2 + ReLU + 池化**

现在网络看到的不是原始像素，而是第一层提取的64个特征图。

1. **卷积操作**（128个3×3的卷积核）

这次卷积核寻找更高级的特征：
- 组合多个边缘形成"角点"
- 组合边缘和纹理形成"眼睛"、"耳朵"的雏形

输出：128个112×112的特征图

2. **池化**
- 尺寸减半：112×112 → 56×56
- 输出：128个56×56的特征图

**第三层、第四层...继续深入**

随着层数加深：
- 特征图尺寸越来越小（56×56 → 28×28 → 14×14 → 7×7）
- 特征图数量越来越多（64 → 128 → 256 → 512）
- 特征越来越抽象（边缘 → 纹理 → 部件 → 整体）

**最后：全连接层**

当特征图变得很小（比如7×7×512）后，展平成一维向量，连接到全连接层：

```
7×7×512 = 25,088个特征
↓
全连接层（4096个神经元）
↓
全连接层（4096个神经元）
↓
输出层（1000个神经元，代表1000个类别）
↓
Softmax（转换成概率）
↓
结果："猫" 95%
```

### CNN的视觉化理解

**第1层看到的：**
```
[边缘特征] [纹理特征]
||| :::
/ \ :.:.:
| | .:.:.
```

**第2-3层看到的：**
```
[眼睛] [耳朵] [胡须]
O O /\ ///
△ / \ ///
```

**第4-5层看到的：**
```
[完整的猫脸]
/\_/\
( o.o )
> ^ <
```

### 经典CNN架构发展史

#### LeNet-5 (1998)：卷积网络的开山之作

**背景：** Yann LeCun为邮政系统开发的手写数字识别

**结构：**
```
输入(32×32)
↓
卷积层1(6个5×5卷积核) → 池化
↓
卷积层2(16个5×5卷积核) → 池化
↓
全连接层(120个神经元)
↓
全连接层(84个神经元)
↓
输出(10个类别：0-9)
```

**意义：** 首次证明CNN可以实用化

#### AlexNet (2012)：深度学习的复兴

**背景：** ImageNet竞赛中以巨大优势获胜，引爆了深度学习热潮

**创新点：**
- 使用**ReLU**激活函数（比Sigmoid快很多）
- 使用**Dropout**防止过拟合
- 使用**GPU加速**训练（两块GPU并行）
- 数据增强（随机裁剪、翻转）

**结构：**
- 5个卷积层
- 3个全连接层
- 6000万个参数

**意义：** 让世界重新认识深度学习的威力

#### VGG (2014)：越深越好

**核心思想：** 用小卷积核（3×3）堆叠深层网络

**比喻：** 与其用一个大滤镜（7×7），不如用多个小滤镜（3×3）叠加。虽然慢一点，但效果更好。

**结构（VGG-16）：**
- 16层（13个卷积层 + 3个全连接层）
- 全部使用3×3的小卷积核
- 1.38亿个参数

**优点：**
结构规整，易于理解
小卷积核参数少，可以堆很深

**缺点：**
参数量太大（500MB+）
训练很慢

#### GoogLeNet / Inception (2014)：宽度优于深度？

**核心思想：** 与其单纯加深，不如让网络"变宽"

**Inception模块：多尺度并行处理**

**比喻：** 就像看一幅画，有人喜欢站近看细节（小卷积核），有人喜欢站远看整体（大卷积核），为什么不让网络同时做这两件事？

```
输入
├─ 1×1卷积 ───────────┐
├─ 1×1卷积 → 3×3卷积 ─┤
├─ 1×1卷积 → 5×5卷积 ─┤
└─ 3×3池化 → 1×1卷积 ─┤
↓
拼接
```

**优点：**
- 计算效率高（用1×1卷积降维）
- 多尺度特征（同时捕捉细节和整体）
- 参数量小（只有500万，是VGG的1/28）

#### ResNet (2015)：残差连接的革命

**问题：** 网络越深越好吗？不一定！

研究发现：56层网络的表现竟然不如20层！这不是过拟合，而是深层网络难以训练（梯度消失）。

**ResNet的解决方案：跳跃连接（Skip Connection）**

**比喻：电梯和楼梯**

传统网络：只有楼梯，从1楼到50楼必须一步步爬（信号逐层传递）
ResNet：有电梯，可以直接从1楼到50楼（跳跃连接）

**残差块 (Residual Block)：**

```
输入x
├─────────────────┐ (跳跃连接)
│ │
↓ │
卷积层 │
↓ │
ReLU │
↓ │
卷积层 │
↓ │
└───────(+)───────┘ (相加)
↓
ReLU
```

**数学表达：**
```
传统：输出 = F(x)
ResNet：输出 = F(x) + x
```

网络只需要学习"残差" F(x)，而不是完整的映射。

**为什么有效？**

如果某一层学习没什么用，网络可以让 F(x)≈0，这样输出≈x，相当于这层被"跳过"了。这比强迫每一层都学习有用特征要容易得多。

**成就：**
- ResNet-152：152层，依然训练良好
- ImageNet错误率：3.57%（人类约5%）
- 深度学习历史上的里程碑

#### DenseNet (2017)：密集连接

**思想：** 既然ResNet的跳跃连接这么有用，为什么不让每一层都连接到所有后续层？

**结构：**
```
输入
├─> 层1 ┐
├─────> 层2 ┐
├──────────> 层3 ┐
└─────────────> 层4
```

每一层都能直接访问前面所有层的特征。

**优点：**
- 特征重用，参数效率高
- 梯度流动更好
- 隐式深度监督

#### EfficientNet (2019)：平衡的艺术

**核心问题：** 如何系统化地扩展网络？

传统做法随意：有人加深度，有人加宽度，有人增大输入分辨率。

**EfficientNet的方案：复合缩放**

同时均衡地增加：
- 深度（层数）
- 宽度（通道数）
- 分辨率（输入大小）

**结果：**
- EfficientNet-B7在ImageNet上达到84.4%准确率
- 但参数量比最好的CNN小8.4倍，推理速度快6.1倍

**比喻：** 不是单纯加大房子的高度、宽度或面积，而是按比例同时扩展，保持整体平衡。

### CNN的优缺点总结

**优点：**
**参数效率高**：通过权值共享大幅减少参数
**利用空间结构**：保留图像的2D结构信息
**平移不变性**：无论物体在图片的哪里都能识别
**层次化特征**：自动学习从低级到高级的特征

**缺点：**
**计算量大**：卷积操作需要大量计算
**需要大量数据**：深层CNN需要海量训练数据
**对旋转敏感**：物体旋转后可能无法识别
**难以处理变形**：物体形变后识别困难

### CNN的应用领域

**计算机视觉：**
- 图像分类：识别图片内容
- 目标检测：找出图片中的物体位置
- 语义分割：标注图片每个像素的类别
- 人脸识别：识别人脸身份
- 姿态估计：检测人体关键点

**其他领域：**
- 医疗影像：肿瘤检测、疾病诊断
- 自动驾驶：识别道路、行人、车辆
- 视频分析：动作识别、事件检测
- 甚至用于非图像数据（如音频频谱图、文本的字符级表示）

## 3.3 循环神经网络 (RNN - Recurrent Neural Network)

### 核心概念：处理序列数据的网络

**问题：** CNN和全连接网络都有一个致命缺陷——它们没有"记忆"。

**例子：理解这句话**

```
"我今天去商店买了一些食物，因为冰箱里什么都没有了。"
```

要理解"因为"，你需要记住前面说了什么。传统网络处理每个词时都是独立的，无法理解上下文。

**RNN的创新：给网络加上记忆**

**比喻：阅读小说**

- **传统网络**：每次只看一个词，看完就忘，像失忆症患者
- **RNN**：边读边记，记住之前读过的内容，像正常人阅读

### RNN的工作原理

**核心机制：循环连接**

```
┌─────┐
输入 → │ RNN │ → 输出
└──↑──┘
│
└─── 隐藏状态(记忆)
```

RNN在处理序列时，每一步都会：
1. 接收当前输入
2. 读取上一步的"记忆"（隐藏状态）
3. 综合两者，更新记忆
4. 输出当前结果

**详细例子：情感分析**

分析这条影评："这部电影开始很无聊，但结局太精彩了！"

**时间步1：** 输入"这部"
- 记忆：[] (空)
- 处理：开始理解句子
- 输出：中性情感
- 更新记忆：[开始分析]

**时间步2：** 输入"电影"
- 记忆：[开始分析]
- 处理：知道在谈论电影
- 输出：中性情感
- 更新记忆：[在谈论电影]

**时间步3：** 输入"开始"
- 记忆：[在谈论电影]
- 处理：电影的"开始"
- 更新记忆：[电影开始...]

**时间步4：** 输入"很无聊"
- 记忆：[电影开始...]
- 处理：哦，开始部分很无聊
- 输出：负面情感（-0.5）
- 更新记忆：[电影开始部分无聊]

**时间步5：** 输入"但"
- 记忆：[电影开始部分无聊]
- 处理：转折！后面可能有变化
- 更新记忆：[前面无聊，但是...]

**时间步6：** 输入"结局"
- 记忆：[前面无聊，但是...]
- 处理：在说结局
- 更新记忆：[开始无聊，但结局...]

**时间步7：** 输入"太精彩了"
- 记忆：[开始无聊，但结局...]
- 处理：结局很精彩！虽然开始无聊，但结局好
- 输出：**正面情感（+0.8）** ✓
- 最终判断：这是一条正面评价

**关键点：** RNN记住了"开始无聊"，也记住了转折词"但"，最终综合判断出整体是正面评价。

### RNN的问题：梯度消失和梯度爆炸

**比喻：传话游戏**

100个人排成一列传话，第一个人说："明天早上9点在图书馆门口集合"

- 传到第10个人：还比较准确
- 传到第50个人：开始变味
- 传到第100个人：可能变成"后天晚上在食堂吃饭"

**RNN的梯度消失问题：**

当序列很长时（比如一段500个词的文章），第1个词的信息传到第500个词时，已经衰减得几乎为0了。网络"忘记"了前面的内容。

**数学原因：**

梯度在反向传播时会连续相乘：
- 如果梯度<1，连乘500次后趋近于0（梯度消失）
- 如果梯度>1，连乘500次后趋近于无穷（梯度爆炸）

**实际影响：**

```
"I grew up in France, so I speak fluent ___."
```

要正确填出"French"，网络需要记住开头的"France"。但如果中间隔了很多词，RNN就会忘记。

### RNN的应用场景

**序列到序列：**
- 机器翻译："I love you" → "我爱你"
- 文本摘要：长文章 → 短摘要
- 对话系统：问题 → 回答

**序列到单值：**
- 情感分析：影评 → 正面/负面
- 文本分类：新闻 → 体育/政治/娱乐
- 视频分类：视频片段 → 动作类别

**单值到序列：**
- 图像描述：图片 → "一只猫躺在沙发上"
- 音乐生成：初始音符 → 完整旋律

**序列到序列（对齐）：**
- 语音识别：音频 → 文本
- 视频标注：为视频每一帧打标签

## 3.4 长短期记忆网络 (LSTM - Long Short-Term Memory)

### 核心概念：RNN的记忆升级版

**问题回顾：** RNN有"短期记忆"，但记性不好，信息很快就忘了。

**LSTM的创新：** 给网络加上"长期记忆"机制，让它能记住重要的信息，忘记不重要的。

**比喻：笔记本vs大脑**

- **RNN**：只用大脑记（短期记忆），一会儿就忘
- **LSTM**：用笔记本记重要的（长期记忆），需要时翻出来看

### LSTM的结构：三个门

LSTM通过三个"门"来控制信息流动：

#### 1. 遗忘门 (Forget Gate)：决定忘记什么

**比喻：清理笔记本**

每过一段时间，你要决定哪些笔记可以扔掉，哪些要保留。

**工作过程：**

```
输入：当前词 + 上一步的记忆
↓
遗忘门判断：这部分记忆还有用吗？
↓
输出：0-1之间的值（0=完全忘记，1=完全保留）
```

**例子：机器翻译**

```
英文：The cat, which was very cute, sat on the mat.
```

当翻译到"sat"时：
- "cat"是主语，很重要 → 保留（遗忘门=0.9）
- "which was very cute"是插入语，翻译"sat"时不重要 → 部分忘记（遗忘门=0.3）
- "the"只是冠词，可以忘记 → 完全忘记（遗忘门=0.1）

#### 2. 输入门 (Input Gate)：决定记住什么

**比喻：记新笔记**

当你学到新知识时，要决定哪些重要到需要记下来。

**工作过程：**

```
输入：当前词 + 上一步的记忆
↓
输入门判断：这个新信息重要吗？值得记吗？
↓
输出：0-1之间的值（0=不记，1=重点记）
```

**例子：情感分析**

```
句子：这部电影很好，但是票价太贵了。
```

- "很好" → 重要！记下来（输入门=0.9）
- "但是" → 转折词！非常重要（输入门=1.0）
- "票价" → 重要，关系到评价（输入门=0.8）
- "了" → 语气词，不重要（输入门=0.1）

#### 3. 输出门 (Output Gate)：决定输出什么

**比喻：回答问题时翻笔记**

你的笔记本里有很多内容，但回答当前问题时，只需要翻出相关的部分。

**工作过程：**

```
输入：当前词 + 上一步的记忆 + 更新后的记忆
↓
输出门判断：记忆中哪部分和当前任务相关？
↓
输出：0-1之间的值（0=不输出，1=完全输出）
```

### LSTM的完整工作流程

**例子：预测下一个词**

句子："我出生在中国，所以我会说___"

**时间步1：** 输入"我"
- 遗忘门：清空记忆（新句子开始）
- 输入门：记住"我"（主语）
- 输出门：输出"主语是我"
- 记忆状态：[主语:我]

**时间步2：** 输入"出生"
- 遗忘门：保留"我"（还有用）
- 输入门：记住"出生"（重要动作）
- 输出门：输出"我出生"
- 记忆状态：[主语:我, 动作:出生]

**时间步3：** 输入"在"
- 遗忘门：保留前面的信息
- 输入门：注意到"在"（表示地点）
- 输出门：提示"接下来是地点"
- 记忆状态：[主语:我, 动作:出生, 待补充:地点]

**时间步4：** 输入"中国"
- 遗忘门：保留关键信息
- 输入门：**重点记住"中国"**（关键信息！）
- 输出门：输出"出生在中国"
- 记忆状态：[主语:我, 出生地:中国]

**时间步5：** 输入"所以"
- 遗忘门：保留"中国"（马上会用到）
- 输入门：记住"所以"（因果关系）
- 输出门：提示"因果推理"
- 记忆状态：[主语:我, 出生地:中国, 关系:因果]

**时间步6：** 输入"会说"
- 遗忘门：重点保留"中国"（快要用了！）
- 输入门：记住"会说"（要填语言）
- 输出门：从记忆中提取"中国" → 输出
- 预测下一个词：**"中文"或"汉语"** ✓

**关键：** LSTM能记住10个词之前的"中国"，在第11个词时准确使用这个信息！

### LSTM vs RNN

| 特性 | RNN | LSTM |
|------|-----|------|
| **记忆能力** | 短期（几步） | 长期（几十甚至上百步） |
| **梯度问题** | 严重的梯度消失 | 大幅缓解 |
| **复杂度** | 简单 | 较复杂（3个门） |
| **参数量** | 少 | 多（4倍于RNN） |
| **训练速度** | 快 | 较慢 |
| **应用效果** | 短序列还行 | 长序列必备 |

### 双向LSTM (Bi-LSTM)

**问题：** 有时候理解当前词，不仅需要看前文，还需要看后文。

**例子：**
```
"The animal didn't cross the road because it was too ___."
```

要判断"it"指的是"animal"还是"road"，需要看后面填什么词：
- tired → it指animal
- wide → it指road

**双向LSTM的方案：**

```
正向LSTM ────────────────────>
输入: The animal didn't cross...
反向LSTM <────────────────────
```

- 正向LSTM：从左往右读，记住前文
- 反向LSTM：从右往左读，记住后文
- 结合两者：同时利用前文和后文

**应用：**
- 机器翻译（需要看完整句再翻译）
- 命名实体识别（判断词性需要上下文）
- 问答系统（理解问题需要完整信息）

### LSTM的应用案例

**1. 机器翻译**

```
英文：I love machine learning.
↓ LSTM编码器（记住整句意思）
[语义编码]
↓ LSTM解码器（逐词生成）
中文：我 爱 机器 学习 。
```

**2. 文本生成**

输入开头："从前有一座山"
LSTM生成后续：
```
从前有一座山，山里有座庙，庙里有个老和尚。
老和尚给小和尚讲故事，故事里说...
```

LSTM学会了：
- 语法结构（主谓宾）
- 故事套路（从前...）
- 长程依赖（前后呼应）

**3. 语音识别**

```
音频波形 → LSTM → 文字
[mel频谱图] 识别 "你好"
```

LSTM处理时间序列的音频数据，记住前面的发音，预测当前音节。

**4. 股票预测**

```
历史价格序列：100, 102, 98, 103, 105...
↓ LSTM（记住价格趋势）
预测下一天：107
```

LSTM记住价格的历史走势，预测未来趋势。

### LSTM的优缺点

**优点：**
**长期依赖**：能记住很久之前的信息
**缓解梯度消失**：三个门控制信息流动
**应用广泛**：几乎所有序列任务都能用

**缺点：**
**计算复杂**：3个门导致计算量是RNN的4倍
**训练慢**：参数多，收敛慢
**难以并行**：必须顺序计算，无法并行加速
**超长序列仍然困难**：100+步的序列依然有挑战

**比喻：** LSTM就像一个有笔记本的学生，比只用大脑记的学生（RNN）强很多，但写笔记也需要时间（计算慢），而且笔记本也有容量限制（超长序列仍困难）。

## 3.5 门控循环单元 (GRU)

### 核心概念：LSTM的简化版

GRU是LSTM的简化版本，将LSTM的三个门简化为两个门：

**更新门 (Update Gate)：** 决定保留多少旧信息，接收多少新信息
**重置门 (Reset Gate)：** 决定忘记多少旧信息

### GRU vs LSTM

| 特性 | LSTM | GRU |
|------|------|-----|
| **门的数量** | 3个（遗忘、输入、输出） | 2个（更新、重置） |
| **参数量** | 较多 | 较少（约LSTM的75%） |
| **训练速度** | 较慢 | 较快 |
| **效果** | 长序列更好 | 短序列差不多 |

**何时选择GRU：**
- 数据量较小时
- 序列不是特别长时
- 需要更快的训练速度时

**何时选择LSTM：**
- 序列很长时
- 需要更强的记忆能力时
- 计算资源充足时

## 3.6 Transformer架构

### 核心概念：注意力就是一切

**问题回顾：** RNN/LSTM虽然能处理序列，但有两个致命缺陷：
1. **无法并行**：必须一个词一个词地处理
2. **长距离依赖困难**：即使是LSTM，超长序列也会有问题

**Transformer的革命性想法：** 完全抛弃循环结构，只用注意力机制！

**比喻：开会讨论**

- **RNN方式**：一个人说完，下一个人才能说（串行）
- **Transformer方式**：所有人同时发言，每个人都能听到所有人的意见（并行）

### 注意力机制 (Attention Mechanism)

**核心问题：** 处理一个词时，应该关注句子中的哪些其他词？

**例子：**
```
"The animal didn't cross the road because it was too tired."
```

当处理"it"时，应该关注哪个词？
- "animal"（因为"tired"说明it指的是动物）
- 而不是"road"

**注意力的计算：**

```
Query (Q)：我想找什么？（当前词的查询）
Key (K)：每个词的标签（用于匹配）
Value (V)：每个词的实际内容

注意力分数 = softmax(Q × K^T / √d) × V
```

**比喻：图书馆找书**

- Query：你想找的书的描述（"关于机器学习的入门书"）
- Key：每本书的标签/关键词
- Value：书的实际内容
- 注意力：根据匹配程度，决定看哪些书

### Self-Attention（自注意力）

**核心思想：** 句子中的每个词都去"关注"句子中的所有词（包括自己）

**例子：处理句子"我爱机器学习"**

处理"学习"这个词时：
- 关注"我"：0.1（不太相关）
- 关注"爱"：0.2（有点相关）
- 关注"机器"：0.4（很相关，因为"机器学习"是一个词组）
- 关注"学习"：0.3（自己）

最终"学习"的表示 = 0.1×"我" + 0.2×"爱" + 0.4×"机器" + 0.3×"学习"

### Multi-Head Attention（多头注意力）

**问题：** 一个注意力头可能只关注一种关系

**解决：** 用多个注意力头，每个头关注不同的关系

**比喻：多角度观察**

- 头1：关注语法关系（主语-谓语）
- 头2：关注语义关系（同义词）
- 头3：关注位置关系（相邻词）
- ...

最后把所有头的结果拼接起来。

### Position Encoding（位置编码）

**问题：** Self-Attention是并行的，不知道词的顺序

"我爱你"和"你爱我"在Self-Attention看来是一样的！

**解决：** 给每个位置加上一个位置编码

```
位置0的编码：[0.1, 0.2, 0.3, ...]
位置1的编码：[0.4, 0.5, 0.6, ...]
位置2的编码：[0.7, 0.8, 0.9, ...]
```

词向量 = 原始词向量 + 位置编码

### Transformer的完整结构

```
输入序列
↓
词嵌入 + 位置编码
↓
┌─────────────────┐
│ Encoder ×N │ ← 编码器（理解输入）
│ - Self-Attention
│ - Feed Forward │
└─────────────────┘
↓
┌─────────────────┐
│ Decoder ×N │ ← 解码器（生成输出）
│ - Masked Self-Attention
│ - Cross-Attention
│ - Feed Forward │
└─────────────────┘
↓
输出序列
```

### Transformer的优势

**1. 并行计算**
- RNN：必须串行，一个词处理完才能处理下一个
- Transformer：所有词同时处理，GPU利用率高

**2. 长距离依赖**
- RNN：信息需要逐步传递，容易丢失
- Transformer：任意两个词直接计算注意力，距离不是问题

**3. 可解释性**
- 注意力权重可以可视化
- 能看到模型在关注什么

### Transformer的应用

**BERT（2018）：** 只用Encoder，用于理解任务
- 文本分类
- 问答系统
- 命名实体识别

**GPT系列（2018-2023）：** 只用Decoder，用于生成任务
- 文本生成
- 对话系统
- 代码生成

**T5、BART：** 完整的Encoder-Decoder，用于序列到序列任务
- 机器翻译
- 文本摘要

## 3.7 生成对抗网络 (GAN)

### 核心概念：生成器与判别器的博弈

**比喻：造假币与验钞**

- **生成器 (Generator)**：造假币的人，目标是造出以假乱真的假币
- **判别器 (Discriminator)**：验钞机，目标是分辨真假币

两者相互对抗，不断进步：
- 造假者越来越厉害 → 假币越来越逼真
- 验钞机越来越厉害 → 检测能力越来越强

最终：造假者能造出完美的"假币"（其实就是真币了）

### GAN的工作原理

```
随机噪声 z
↓
┌─────────────┐
│ 生成器 G │ → 生成假图片
└─────────────┘
↓
假图片 + 真图片
↓
┌─────────────┐
│ 判别器 D │ → 判断真假
└─────────────┘
↓
真/假的概率
```

**训练过程：**

1. **训练判别器**
- 给判别器看真图片，标签=1（真）
- 给判别器看假图片，标签=0（假）
- 判别器学习区分真假

2. **训练生成器**
- 生成器生成假图片
- 希望判别器把假图片判断为真
- 生成器学习生成更逼真的图片

3. **重复1-2**，直到生成器能生成以假乱真的图片

### GAN的数学表达

**目标函数（极小极大博弈）：**

```
min_G max_D V(D, G) = E[log D(x)] + E[log(1 - D(G(z)))]
```

- D想最大化：正确判断真假
- G想最小化：让D判断错误

### 经典GAN变体

**DCGAN (Deep Convolutional GAN)**
- 用卷积网络替代全连接网络
- 生成更高质量的图片
- 训练更稳定

**WGAN (Wasserstein GAN)**
- 改进损失函数
- 解决训练不稳定问题
- 解决模式崩塌问题

**StyleGAN**
- 控制生成图片的风格
- 可以分层控制（粗糙特征、精细特征）
- 生成超高质量人脸

**CycleGAN**
- 无需配对数据
- 图像风格转换（照片→油画）
- 跨域转换（马→斑马）

### GAN的应用

**1. 图像生成**
- 生成逼真的人脸（ThisPersonDoesNotExist.com）
- 生成艺术作品
- 生成游戏场景

**2. 图像编辑**
- 图像修复（去除水印、修复老照片）
- 图像超分辨率（提高图片清晰度）
- 换脸（DeepFake）

**3. 数据增强**
- 生成训练数据
- 解决数据不足问题

**4. 风格迁移**
- 照片变油画
- 白天变夜晚
- 夏天变冬天

### GAN的挑战

**1. 训练不稳定**
- 生成器和判别器需要平衡
- 一方太强会导致训练失败

**2. 模式崩塌 (Mode Collapse)**
- 生成器只生成少数几种图片
- 缺乏多样性

**3. 评估困难**
- 没有明确的损失函数来衡量生成质量
- 需要人工评估或FID等指标

---

## 3.8 自编码器 (AutoEncoder)

### 核心概念：压缩与重建

**比喻：压缩文件**

把一个100MB的文件压缩成10MB，然后再解压回100MB。如果解压后的文件和原文件一样，说明压缩算法很好。

**自编码器的结构：**

```
输入 x (784维)
↓
┌─────────────┐
│ 编码器 E │ → 压缩
└─────────────┘
↓
隐藏表示 z (32维) ← 瓶颈层
↓
┌─────────────┐
│ 解码器 D │ → 重建
└─────────────┘
↓
重建 x' (784维)

目标：让 x' 尽可能接近 x
```

### 自编码器的应用

**1. 降维**
- 比PCA更强大
- 能学习非线性关系

**2. 去噪**
- 输入带噪声的图片
- 输出干净的图片

**3. 特征学习**
- 隐藏层学到的是数据的本质特征
- 可以用于其他任务

**4. 异常检测**
- 正常数据能很好地重建
- 异常数据重建误差大

---

## 3.9 变分自编码器 (VAE)

### 核心概念：概率生成模型

**普通自编码器的问题：** 隐藏空间不连续，无法用于生成

**VAE的改进：** 让隐藏空间服从正态分布

```
输入 x
↓
编码器 → 均值μ, 方差σ
↓
采样 z ~ N(μ, σ) ← 从正态分布采样
↓
解码器 → 重建 x'
```

**VAE的优势：**
- 隐藏空间连续、平滑
- 可以从隐藏空间采样生成新数据
- 可以在隐藏空间插值

---

## 3.10 图神经网络 (GNN)

### 核心概念：处理图结构数据

**问题：** CNN处理网格数据（图像），RNN处理序列数据，但很多数据是图结构：
- 社交网络（用户之间的关系）
- 分子结构（原子之间的键）
- 知识图谱（实体之间的关系）

**GNN的思想：** 每个节点聚合邻居的信息

```
节点A的新表示 = 聚合(节点A, 邻居B, 邻居C, 邻居D)
```

**比喻：** 一个人的特征不仅取决于自己，还取决于他的朋友圈

### GNN的应用

- 社交网络分析（推荐好友）
- 药物发现（预测分子性质）
- 交通预测（路网流量）
- 推荐系统（用户-物品图）

---

## 本章总结

我们学习了深度学习的主要网络架构：

| 网络类型 | 适用数据 | 核心特性 | 典型应用 |
|---------|---------|---------|---------|
| **全连接网络** | 表格数据 | 简单通用 | 分类、回归 |
| **CNN** | 图像数据 | 局部感知、权值共享 | 图像识别、目标检测 |
| **RNN/LSTM** | 序列数据 | 时间记忆 | 文本、语音 |
| **Transformer** | 序列数据 | 自注意力、并行 | NLP、CV |
| **GAN** | 生成任务 | 对抗训练 | 图像生成 |
| **AutoEncoder** | 无监督 | 压缩重建 | 降维、去噪 |
| **GNN** | 图数据 | 邻居聚合 | 社交网络、分子 |

**架构选择指南：**

```
你的任务是什么？
├─ 图像相关 → CNN（或Vision Transformer）
├─ 文本相关 → Transformer（BERT/GPT）
├─ 序列预测 → LSTM/Transformer
├─ 生成任务 → GAN/VAE/Diffusion
├─ 图结构数据 → GNN
└─ 表格数据 → 全连接网络（或传统ML）
```
