## 第一章：机器学习入门

### 1.1 什么是机器学习
- **核心概念**：让计算机从数据中学习规律
- **比喻**：机器学习 = 教小孩认字
- 传统编程：告诉电脑"这是A，那是B"（规则驱动）
- 机器学习：给电脑看很多A和B，让它自己总结规律（数据驱动）

### 1.2 机器学习的三要素
- **数据**：学习的原材料（比喻：食材）
- **模型**：学习的方法（比喻：菜谱）
- **算法**：优化的过程（比喻：烹饪技巧）

### 1.3 机器学习的分类
- **监督学习**：有标准答案的学习（老师教学）
- **无监督学习**：自己探索规律（自学成才）
- **强化学习**：试错中学习（打游戏升级）

### 1.4 机器学习 vs 深度学习
- 机器学习：需要人工设计特征
- 深度学习：自动学习特征
- **比喻**：
- 机器学习 = 给孩子总结"苹果是红的、圆的"
- 深度学习 = 让孩子自己看图总结苹果的特征

### 1.5 机器学习的应用场景
- 推荐系统：淘宝、抖音的推荐
- 图像识别：人脸解锁、车牌识别
- 自然语言处理：智能客服、机器翻译
- 预测分析：股票预测、天气预报

## 第三章：经典机器学习算法

### 3.1 K近邻算法 (KNN)
- **核心思想**：物以类聚，人以群分
- **比喻**：判断一个人的性格，看他身边最亲近的5个朋友
- 算法原理与流程
- 距离度量：欧氏距离、曼哈顿距离
- K值的选择
- 优缺点分析
- **实战案例**：鸢尾花分类

### 3.2 线性回归 (Linear Regression)
- **核心思想**：找一条直线拟合数据
- **比喻**：根据身高预测体重，画一条最合适的直线
- 一元线性回归
- 多元线性回归
- 损失函数：均方误差(MSE)
- 梯度下降优化
- **实战案例**：房价预测

### 3.3 逻辑回归 (Logistic Regression)
- **核心思想**：用S型曲线做分类
- **比喻**：根据学习时间预测考试是否及格（是/否）
- Sigmoid函数
- 二分类与多分类
- 损失函数：交叉熵
- **实战案例**：垃圾邮件识别

### 3.4 决策树 (Decision Tree)
- **核心思想**：像玩"20个问题"游戏一样分类
- **比喻**：医生问诊（发烧吗？→咳嗽吗？→...→诊断结果）
- 信息增益与基尼系数
- 树的生成与剪枝
- 优缺点分析
- **实战案例**：贷款审批预测

### 3.5 随机森林 (Random Forest)
- **核心思想**：三个臭皮匠顶个诸葛亮
- **比喻**：多个专家投票决定（集体智慧）
- Bagging思想
- 特征重要性
- 超参数调优
- **实战案例**：信用卡欺诈检测

### 3.6 支持向量机 (SVM)
- **核心思想**：找一条最优分界线
- **比喻**：在两群人中间画一条最宽的"楚河汉界"
- 最大间隔分类器
- 核函数：线性、多项式、RBF
- 软间隔与硬间隔
- **实战案例**：手写数字识别

### 3.7 朴素贝叶斯 (Naive Bayes)
- **核心思想**：基于概率的分类
- **比喻**：根据症状推测疾病（发烧+咳嗽→感冒的概率是多少？）
- 贝叶斯定理
- 高斯朴素贝叶斯
- 多项式朴素贝叶斯
- **实战案例**：文本分类

### 3.8 K均值聚类 (K-Means)
- **核心思想**：物以类聚，自动分组
- **比喻**：把学生按成绩自动分成优良中差几组
- 算法流程：初始化→分配→更新→迭代
- 肘部法则选择K值
- 优缺点分析
- **实战案例**：客户分群

### 3.9 主成分分析 (PCA)
- **核心思想**：降维，保留最重要的信息
- **比喻**：把3D物体投影到2D平面，尽量保持原貌
- 特征值与特征向量
- 方差解释率
- 应用场景
- **实战案例**：人脸识别预处理

## 第四章：模型评估与优化

### 4.1 数据集划分
- **训练集、验证集、测试集**
- **比喻**：
- 训练集 = 课本（学习用）
- 验证集 = 模拟考（调整策略）
- 测试集 = 期末考（最终检验）
- 划分比例：70/15/15 或 80/10/10
- 交叉验证 (K-Fold)

### 4.2 分类模型评估
- **准确率 (Accuracy)**：整体正确率
- **精确率 (Precision)**：预测为正的有多少是真正
- **比喻**：撒网捕鱼，捞上来的鱼有多少是目标鱼
- **召回率 (Recall)**：真正例有多少被找出来
- **比喻**：池子里的目标鱼有多少被捞上来
- **F1分数**：精确率和召回率的调和平均
- **混淆矩阵**：分类结果的详细展示
- **ROC曲线与AUC**：模型性能的综合评估

### 4.3 回归模型评估
- **均方误差 (MSE)**：预测值与真实值的平方差
- **均方根误差 (RMSE)**：MSE的平方根
- **平均绝对误差 (MAE)**：预测值与真实值的绝对差
- **R²决定系数**：模型拟合优度

### 4.4 过拟合与欠拟合
- **欠拟合**：模型太简单，学不会
- **比喻**：用直线拟合曲线数据（太粗糙）
- **过拟合**：模型太复杂，死记硬背
- **比喻**：把训练数据背下来，遇到新数据就懵了
- **解决方法**：
- 增加数据量
- 正则化 (L1/L2)
- 交叉验证
- 特征选择

### 4.5 超参数调优
- **什么是超参数**：模型训练前需要设定的参数
- **比喻**：做菜前要决定的火候、时间（不是做菜过程中调整的）
- **网格搜索 (Grid Search)**：遍历所有组合
- **随机搜索 (Random Search)**：随机尝试
- **贝叶斯优化**：智能搜索

### 4.6 特征工程
- **特征构造**：创造新特征
- **比喻**：从"出生日期"计算出"年龄"
- **特征组合**：组合多个特征
- **特征变换**：对数变换、多项式变换
- **特征重要性分析**

## 第六章：Scikit-learn实战

### 6.1 Scikit-learn简介
- **核心概念**：Python最流行的机器学习库
- **比喻**：Scikit-learn = 机器学习的工具箱
- 统一的API设计
- 丰富的算法库

### 6.2 数据预处理模块
- `StandardScaler`：标准化
- `MinMaxScaler`：归一化
- `LabelEncoder`：标签编码
- `OneHotEncoder`：独热编码
- `train_test_split`：数据集划分

### 6.3 模型训练与预测
- `fit()`：训练模型
- `predict()`：预测
- `score()`：评估
- `fit_predict()`：训练并预测（聚类）

### 6.4 模型评估模块
- `accuracy_score`：准确率
- `precision_score`：精确率
- `recall_score`：召回率
- `f1_score`：F1分数
- `confusion_matrix`：混淆矩阵
- `classification_report`：分类报告

### 6.5 模型选择模块
- `GridSearchCV`：网格搜索
- `RandomizedSearchCV`：随机搜索
- `cross_val_score`：交叉验证

### 6.6 Pipeline管道
- **核心概念**：把多个步骤串联起来
- **比喻**：流水线作业（预处理→特征选择→模型训练）
- 代码示例与最佳实践
